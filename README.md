# trimeric_entry_inhibitor
Analysis code for Mou et al., "A SARS-CoV-2 entry-inhibitor trimerizes to lock the spike protein in a closed conformation". 

spike_escape_mutation_analysis_main.cc is a self-contained program for parsing the barcoded .fastq data and extracting mutation frequencies.
build_tree_and_table.py constructs the phylogenetic tree and mutation table figure.

See comments in the source files for instructions.
